03 The real desktop pipeline

Four small steps.
One private loop.

01 / CAPTURE

Listen until silence.

PyAudio records 16 kHz mono sound. WebRTC VAD notices when you stop speaking, so no button press is needed.

02 / TRANSCRIBE
WHISPER

Turn sound into words.

Whisper.cpp runs on the computer and writes the transcript. Audio does not need to be uploaded to the MurmurX app.

03 / REASON
Q2.53B

Ask a local model.

Qwen 2.5 3B receives a short system instruction plus the latest conversation turns, then returns a concise answer.

04 / SPEAK

Hear the answer.

The operating system reads the answer aloud. Then the loop is ready for the next question.
